## 三、简答题（每题5分，共2题，10分）
### 1. 简述创建线程的两种方式，并说明它们的主要区别。
**答案**：
- **方式一：继承Thread类**  
  定义类继承Thread，重写`run()`方法，创建该类对象，调用`start()`启动线程。  
- **方式二：实现Runnable接口**  
  定义类实现Runnable，重写`run()`，创建Runnable实现类对象，作为参数传给Thread构造器，创建Thread对象后调`start()`启动。  

**区别**：  
- **继承限制**：继承Thread类后，因Java单继承，无法再继承其他类；实现Runnable接口无此限制，更灵活。  
- **资源共享**：实现Runnable时，多个线程可共享同一个Runnable实现类对象的资源；继承Thread类，每个线程是独立对象，难共享（除非用静态变量等特殊方式 ）。  

### 2. 简述List、Set、Map三大集合的核心区别，并各举一个常用实现类。
**答案**：  
- **List**：有序（元素按插入顺序或自定义顺序排列 ）、可重复；常用实现类如`ArrayList`（动态数组，查询快 ）、`LinkedList`（链表，增删快 ）。  
- **Set**：无序（元素无固定顺序 ）、不可重复（靠`hashCode`和`equals`保证 ）；常用实现类如`HashSet`（哈希表实现，存取快 ）、`TreeSet`（红黑树实现，可排序 ）。  
- **Map**：存储键值对（key - value ），key唯一、value可重复；常用实现类如`HashMap`（哈希表实现，常用 ）、`TreeMap`（红黑树实现，key可排序 ）。  

这些解析能帮你梳理知识点、明确对错逻辑，复习时可重点关注错题对应的考点，加深理解 。
